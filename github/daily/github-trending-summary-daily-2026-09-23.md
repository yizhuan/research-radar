## Notable Shifts

Today's list is less about standalone model releases and more about the surrounding operating layer: orchestration, harnesses, skills, tool routing, and agent-native interfaces. The presence of office, finance, and design projects suggests the trend is broadening from developer experiments into complete software surfaces.

## Takeaway

The leading signal is a maturing agent ecosystem. Developers are investing in the connective tissue that lets agents use tools, follow workflows, and operate inside real applications, while Go, Python, and TypeScript divide infrastructure, automation, and user-facing integration roles. Projects that make existing software legible and controllable to agents are the clearest category to watch.
