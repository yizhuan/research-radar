## Trending Technologies and Themes

- **Agent orchestration and runtime infrastructure:** `google/ax`, `agent-substrate/substrate`, and `strands-agents/harness-sdk` focus on coordinating, controlling, or hosting agents rather than merely calling a model.
- **Agent-native software interfaces:** `HKUDS/CLI-Anything`, `BuilderIO/agent-native`, and `dream-num/univer` point toward making existing software and work surfaces directly operable by agents.
- **Coding-agent operations and methodology:** `davila7/claude-code-templates` and `obra/superpowers` show demand for configuration, reusable skills, and disciplined development workflows.
- **Languages:** Among the selected ten, Python leads with 4 repositories, TypeScript has 3, Go has 2, and Shell has 1.

## Notable Shifts

The notable shift is from model-centric projects toward the surrounding control plane: orchestration, harnesses, skills, CLIs, and agent-compatible work surfaces. The presence of `univer` and `OpenStock` also suggests the trend is broadening from developer tools into agent-enabled productivity and data applications.

## Takeaway

Today’s GitHub momentum is concentrated in the infrastructure needed to make agents reliable participants in real software workflows. The common product boundary is no longer just an AI model; it is the harness, interface, skill system, and domain application around that model. Go, Python, and TypeScript are all participating, but Python remains the most common language in this snapshot.
