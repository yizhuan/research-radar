## Takeaway

The strongest signal is the shift from agents that only write code toward packaged workflows and tools that produce inspectable artifacts or analyze software. Creative generation, engineering skills and low-level analysis all show up together. Treat extreme weekly star-gain figures cautiously: GitHub’s view and current REST metadata corroborate the repositories and current star counts, but not the historical net additions or their provenance.
